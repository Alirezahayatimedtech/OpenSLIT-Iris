# Annotation examples

## Target segmentation output

The following figure provides collaborators with a visual example of the intended OpenSLIT-Iris annotation result.

![Slit-lamp iris segmentation example](assets/annotation_segmentation_example.svg)

The example shows these target classes:

- pupil;
- visible iris;
- reflection;
- slit-beam artefact;
- eyelid occlusion;
- eyelash occlusion.

This image is an explanatory schematic, not a pixel-level ground-truth mask. Annotators must follow the visible-boundary, exclusion, uncertainty, and class-precedence rules in [Annotation Protocol v1.0](ANNOTATION_PROTOCOL_V1.md).

Accepted and rejected real-image examples will be added after the independent pilot annotations have been adjudicated.
