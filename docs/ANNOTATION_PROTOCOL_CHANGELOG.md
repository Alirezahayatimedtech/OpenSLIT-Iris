# Annotation protocol changelog

## 1.0.0 — 2026-07-27

Initial frozen pilot specification.

- Defines pupil, visible iris, reflection, slit-beam, eyelid, eyelash, uncertain, and background classes.
- Defines visible-only annotation and class-precedence rules.
- Restricts the protocol to frontal or nearly frontal visible-light slit-lamp photographs.
- Adds a machine-readable JSON schema, manifest template, mask validator, and tests.
- Prohibits patient identifiers, laterality, diagnosis, and clinical outcomes in shared annotation manifests.
